Biografia de Chester Bennington

Projeto desenvolvido em HTML5 e CSS3, com o objetivo de apresentar a trajetória pessoal e musical de Chester Bennington, vocalista da banda Linkin Park.

 Sobre o projeto

A página apresenta uma breve biografia do cantor, destacando acontecimentos de sua vida e momentos importantes de sua carreira musical.

O projeto também explora recursos de estilização em CSS para construir uma identidade visual inspirada na atmosfera do rock.

 Tecnologias utilizadas

- HTML5: estruturação do conteúdo da página.
- CSS3: estilização de textos, cores, tamanhos e alinhamentos.
- Google Fonts: utilização de fontes personalizadas.

 Conteúdo

- Início de vida;
- Carreira musical;
- Trajetória no Linkin Park;
- Projetos musicais paralelos.

 Identidade visual

A página utiliza:

- Fundo preto;
- Títulos em rosa;
- Textos em branco;
- Fontes personalizadas;
- Diferentes estilos de alinhamento e formatação.

 Objetivo de aprendizagem

Praticar conceitos básicos de desenvolvimento web, explorando a estrutura HTML, a aplicação de estilos CSS e a organização de conteúdo em uma página.

 Status do projeto

Concluído — projeto desenvolvido para fins de aprendizagem.
